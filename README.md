# Koyo Interview Tasks

This repository contains my solutions to the technical interview assessment tasks for Koyo. The tasks focus on practical problem-solving, API integration, debugging, and backend development using Python.

## Assessment Tasks

### 1. Positionstack API – Reverse Geocoding
- Integrate the Positionstack API using Python.
- Retrieve location information using latitude and longitude coordinates.
- Extract and display the first full formatted address from the API response.

### 2. Payment Reconciliation
- Investigate and debug the provided payment reconciliation script.
- Understand the transaction data and reconciliation requirements.
- Implement the necessary fixes and verify the output.
